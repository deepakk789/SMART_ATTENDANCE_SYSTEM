How it works

Three steps from photo to attendance report.

1

Upload Group Photo

Drag and drop any classroom photo — MTCNN locates every face in the image simultaneously.

2

AI Identifies Students

FaceNet generates 128-D embeddings for each detected face and matches them against the student database using Euclidean distance.

3

Attendance Marked

A full present/absent report is generated instantly. Download as CSV or view history by date.

The Technology

Industry-grade models, not toy classifiers.

🔍

MTCNN Face Detection

Multi-task Cascaded CNN — 3-stage pipeline (P-Net, R-Net, O-Net) that detects faces at any scale and angle in group photos.

🧠

FaceNet Recognition

Google's Inception-ResNet-v1 trained with Triplet Loss on VGGFace2 — maps any face to a 128-dimensional embedding vector.

⚡

NumPy Vectorized Matching

Euclidean distance computed against all stored embeddings simultaneously using NumPy's C-level operations — 100× faster than Python loops.

🗄️

Two-Phase Architecture

Phase 1: Register students (video → embeddings.pkl). Phase 2: Attendance (photo → match → CSV). Phase 2 is near-instant because Phase 1 pre-computed all fingerprints.
